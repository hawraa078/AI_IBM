# 🚀 Styles master - The Floating Smart Assistant for Figma

Welcome to the future of user interface design! 
**Styles master** is a floating smart assistant specifically engineered to eliminate the "Context Switching" problem that UI/UX designers face daily. The project seamlessly integrates a visual asset archiving system with an AI-powered conversational tool, providing instant support and precise design evaluation without ever forcing you to leave your Figma workspace.

---

## ✨ Key Features

* **🎨 Interactive Asset Folders:** A sleek, visual interface that allows designers to extract, save, and instantly apply color swatches and typography styles to their active selections with a single click.
* **🤖 The Floating Chatbot:** A smart conversational assistant powered by the Google Gemini API. It reads the selected UI with pixel-perfect accuracy and responds to designer queries via integrated chat bubbles (e.g., requesting a contrast accessibility check or spacing evaluation).
* **⚡ Lightweight & Unobtrusive Design:** A minimalist floating popup that consumes zero canvas real estate, ensuring the designer's workflow remains focused and uninterrupted.
* **☁️ Cloud Processing:** Payload data (Base64 + Text) is securely routed to an independent Node.js server, guaranteeing lightning-fast performance without draining your local machine's resources.

## ⚙️ How to Run Locally (For Judges)

The Backend server is already deployed and live on Render. To test and experience the plugin locally, please follow these simple steps:

### Prerequisites:
* Download and install the **Figma Desktop App** (Local development plugins only run on the desktop version).
* Download this repository (Clone or Download ZIP) and extract it to your local machine.

### Installation Steps:
1. Launch the **Figma** desktop app and open any Design File.
2. From the top-left menu, click the **Figma Logo** (or right-click anywhere on the canvas).
3. Navigate to **Plugins** > **Development** > **Import plugin from manifest...**.
4. Browse your local files, locate the extracted project folder, and select the `manifest.json` file.
5. The plugin will instantly initialize in your workspace.
6. Select any UI frame or element in Figma, click the floating **Styles master** icon, and start chatting with your new design assistant!
